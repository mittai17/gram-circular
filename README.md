# GRAM-CIRCULAR

> Rural MLP Waste Management & Circular Economy Platform
> Smart India Hackathon 2026 | Problem ID: 26259

## Quick Start

```bash
# Install all dependencies
pnpm install

# Start web app (development)
pnpm dev:web

# Start API server
pnpm dev:api
```

## Apps
| App | Description | Port |
|---|---|---|
| `apps/web` | Next.js web portal | 3000 |
| `apps/api` | NestJS REST API | 3001 |
| `apps/mobile` | Expo mobile app | 8081 |
| `apps/optimizer` | Python OR-Tools optimizer | 8000 |
